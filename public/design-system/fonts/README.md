# WhiteDot LIMEX Brand Fonts

Source checked: LIMEX Brand Guidelines PDF from TBM.

The guideline recommends sans-serif fonts for LIMEX text:

- Noto Sans Bold
- Yu Gothic Bold

Available locally in `C:\Users\rbhan\OneDrive\Desktop\whitedot\fonts`:

- `NotoSansCJKjp-Bold.otf` - open-source Noto Sans CJK Japanese Bold from the official `notofonts/noto-cjk` GitHub repository.
- `NotoSansCJKjp-Regular.otf` - matching regular weight for normal text.
- `NotoSansCJK-LICENSE.txt` - license file from the same repository.

Repository note:

- The GitHub Pages design-system preview loads Noto Sans JP from Google Fonts to avoid committing large CJK font binaries into the website repository.

Not copied:

- Yu Gothic Bold is a Microsoft/Windows system font, not an open web font. It is already installed on this computer at `C:\Windows\Fonts\YuGothB.ttc`.
