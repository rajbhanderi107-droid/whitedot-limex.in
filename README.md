# WhiteDot LIMEX Website

Premium single-page website for WhiteDot LIMEX / CR LIMEX regional distribution and education across Gujarat, Rajasthan, Diu, Daman, and Goa.

**Built with:** React, TypeScript, Three.js, Vite

## Local development

```bash
npm install
npm run dev```

## Production build

```bash
npm run build
```
