# BORN OF LIMEX — 40s Cinematic Brand Film (Production Package)

**WhiteDot x LIMEX** · premium sustainability launch film · 16:9 hero + 9:16 social cut · exactly 40.0s @ 24fps.

A 40-second cinematic brand film about LIMEX as a sustainable material innovation — from carbon/mineral origin, through limestone (calcium carbonate) intelligence bonded with resin, to real product forms and responsible adoption.

## How to use
1. Read `director-treatment.md` + `master-storyboard.md` for intent.
2. Generate stills from `ai-image-prompts.md`, then clips from `runway-seedance-veo-prompts.md` (Kling free tier / Firefly first).
3. Transitions via `google-flow-transition-prompts.md`.
4. VO (`voiceover-script.md`) + music/SFX (`sound-design-and-music.md`).
5. Assemble per `production-workflow.md`; grade via `color-grade-and-lookbook.md`; polish via `adobe-postproduction-workflow.md`.
6. Run `quality-control-checklist.md` before export.

## Brand-safety note
LIMEX = calcium-carbonate mineral (~50–80%) bonded with polyolefin resin, by TBM Co., Ltd. (Japan); WhiteDot markets it in India. Language stays grounded: "mineral-based", "reduces plastic dependence", "responsible material pathway". No carbon-negative / 100% biodegradable / "made from CO2" claims.
