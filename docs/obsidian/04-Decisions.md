# Architecture and Design Decisions

## ADR-001 — Stack Choice
Decision: React 19 + TypeScript + Vite + Three.js + GSAP + Framer Motion
Reason: Modern, fast, supports cinematic 3D animations, TypeScript for safety

## ADR-002 — Deployment
Decision: GitHub Pages (frontend) + Render Singapore (backend)
Reason: Cost-effective, performant for South Asia region

## ADR-003 — Design System
Decision: Apple-level minimal design, premium sustainability brand
Reason: Client-ready, trustworthy for B2B and investor presentations

## ADR-004 — Project Memory
Decision: Obsidian vault in docs/obsidian/ synced via Obsidian Git
Reason: Keeps all knowledge in version control, readable by Claude Code
