# WhiteDot Obsidian Vault — Project Command Center

> Open this folder as your Obsidian vault to access all project notes.

## Vault Structure
- 00-Dashboard.md — Main project dashboard
- 01-Vision.md — Brand vision and goals
- 02-Tasks.md — Current task list
- 03-Bugs.md — Bug tracker
- 04-Decisions.md — Design and architecture decisions
- 05-ClientNotes.md — Client direction and feedback
- 06-FeatureList.md — Planned features
- 07-MeetingNotes.md — Session notes

## Setup
1. Open Obsidian > Open Folder as Vault > select docs/obsidian/
2. Install Obsidian Git community plugin
3. Configure: auto-pull on open, auto-commit every 5 min, push on close
4. Claude Code reads these files as project memory
