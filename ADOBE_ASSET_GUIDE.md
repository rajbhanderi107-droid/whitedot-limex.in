# ADOBE ASSET GUIDE — WHITE DOT LIMEX

> **Role:** Creative Asset Reference
> **Adobe Assets Path:** `/public/assets/adobe/`

---

## Asset Standards

| Format | Use Case | Max Size |
|--------|----------|----------|
| `.svg` | Logos, icons | — |
| `.webp` | Hero images, product renders | < 300KB |
| `.png` | Transparent assets | < 500KB |
| `.mp4 H.264` | Videos | < 10MB |

---

## Naming Convention

```
limex-hero-frame.webp
whitedot-logo.svg
limex-bottle-render.webp
launch-film-poster.webp
limex-icon-[name].svg
```
